# Calculator

A simple single-screen calculator built with Flutter and Dart. It uses Material 3,
follows the system light/dark theme, and adapts its layout to portrait and landscape.

## Run the app

This repository includes the Flutter package manifest and web scaffolding. To run
it in VS Code, open this repository's `calculator` folder (the folder containing
`pubspec.yaml`). The workspace setting searches up to five directory levels for
Flutter projects if you open a parent folder instead. Install Flutter, run
`flutter pub get`, then run `flutter run` with a connected device or simulator.

The app's Dart source files are `lib/main.dart`, `lib/calculator_logic.dart`, and
`lib/calculator_button.dart`.
